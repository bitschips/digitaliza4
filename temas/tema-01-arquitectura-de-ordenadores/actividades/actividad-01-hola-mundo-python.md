# Actividad 01. El viaje de una línea de código

**Tema:** Arquitectura de ordenadores · 4.º ESO  
**Tiempo orientativo:** 15-20 minutos  
**Materiales:** ordenador con Python 3, editor de texto o código (por ejemplo, KWrite) y terminal.

[Índice de actividades](README.md) · [Idea de vídeo relacionado](../videos/video-01-viaje-linea-python.md)

## Objetivo

Crear, guardar y ejecutar un programa mínimo en Python y explicar qué función desempeñan el SSD, la memoria RAM, la CPU y la pantalla.

## Instrucciones para el alumnado

1. Abre un editor de texto o de código.
2. Crea un archivo nuevo y escribe:

   ```python
   # Mi primer programa
   print("Hola mundo")
   ```

3. Guarda el archivo con el nombre `hola.py` en tu carpeta personal.
4. Abre la terminal, accede a esa carpeta y ejecuta `python3 hola.py` (en algunos sistemas el comando es `python hola.py`).
5. Comprueba que aparece el mensaje `Hola mundo`.
6. Cambia el mensaje por tu nombre o una frase de clase, guarda y vuelve a ejecutar.
7. En tu cuaderno o documento, dibuja cuatro elementos —SSD, RAM, CPU y pantalla— y escribe **una frase sobre lo que hace cada uno** al ejecutar el programa.

## Preguntas para comprender

- ¿Dónde se conserva `hola.py` cuando apagas el ordenador?
- ¿Por qué se necesita RAM al ejecutar programas?
- ¿La CPU interpreta directamente el texto Python? ¿Qué programa interviene?
- ¿Qué verías si ejecutaras `print("Adiós")`?

## Entrega

Una captura del editor con el código, otra de la terminal con el resultado y el esquema de los cuatro componentes.

## Criterios de logro

- Crea y guarda correctamente un archivo `.py`.
- Ejecuta el programa y modifica el mensaje.
- Distingue almacenamiento permanente, memoria de trabajo, procesamiento y salida.

**Nota docente:** el intérprete de Python ejecuta el programa mediante instrucciones de máquina en la CPU; la representación gráfica de la terminal puede involucrar a la GPU. El esquema es una simplificación útil para iniciación.
