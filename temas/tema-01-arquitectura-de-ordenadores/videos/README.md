## Objetivo

Registrar **ideas y guiones para futuros vídeos didácticos** que permitan comprender visualmente los conceptos de este tema. Los vídeos aún no están generados: los documentos Markdown son propuestas editables que podrán utilizarse más adelante con un generador de vídeo mediante IA.

## Plantilla para nuevas propuestas

Cada archivo de idea debe recoger: **objetivo didáctico, público, duración estimada, conceptos clave, secuencia visual/escenas, narración sugerida, indicaciones para un generador de vídeo IA, posibles errores conceptuales, actividad complementaria y estado** (idea / guion / generado / revisado / publicado).

Se pueden proponer escenas, ilustraciones y animaciones sin dar por hecho que el vídeo existe. Enlazar el vídeo real solo cuando esté generado y verificado. Mantener los recursos adecuados a 4.º ESO.
