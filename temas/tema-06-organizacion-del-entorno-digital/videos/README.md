# Ideas de vídeos — Tema 6. Organización del entorno digital

[Volver al índice general](../../../README.md)

## Objetivo

Registrar ideas y guiones para futuros vídeos didácticos que permitan comprender visualmente los conceptos de este tema. Los vídeos todavía no se han generado; estos archivos Markdown son propuestas editables para una futura herramienta de generación de vídeo mediante IA.

## Índice de ideas

_Aún no hay ideas registradas. Añadir cada propuesta en un archivo `video-NN-titulo.md` y enlazarla aquí._

## Plantilla para nuevas propuestas

Para cada idea incluir: objetivo didáctico, duración aproximada, conceptos clave, escenas o secuencia visual, narración sugerida, indicaciones para IA generativa de vídeo, comprobación de exactitud, actividad relacionada y estado (idea / guion / generado / revisado / publicado).

Enlazar el vídeo real únicamente cuando exista y se haya comprobado. Adecuar el lenguaje a 4.º ESO.
